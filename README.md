# Paper & Pulse Hub

Build a modern, editorial-style website for Paper & Pulse, the college magazine and publication.

For now, build only the landing page and core structure. The magazine PDFs will be uploaded later, so the website should be designed to easily accommodate and display multiple magazine editions as PDFs inside the website.

1. Landing Page

The landing page should prominently feature:

PAPER & PULSE
The Magazine

A short introductory section about Paper & Pulse as the official magazine/publication platform.

Include sections for:

About Paper & Pulse

Magazine

Activities

Office Bearers

Keep the landing page visually engaging but professional, with a strong editorial/magazine aesthetic.

2. Office Bearers

Create an Office Bearers section with profile cards.

For now, leave the photo area as an empty placeholder because photos will be added later.

Each card should contain:

Empty photo placeholder

Name

Designation

I will provide the names and designations later, so create the structure with placeholder entries for now.

3. Magazine

Create a dedicated Magazine section where future magazine editions can be displayed.

For now, use placeholder magazine editions.

The design should anticipate multiple PDF editions, with each edition having:

Magazine cover/thumbnail

Magazine name/edition

Publication date or year

View Magazine button

When PDFs are uploaded later, clicking View Magazine should open the PDF inside the website itself, preferably in an embedded PDF viewer rather than forcing the user to download it.

Make the magazine section easy to update with new editions.

4. Activities

Create an Activities section showcasing activities conducted by Paper & Pulse.

Use clean cards or editorial blocks for activities, with:

Activity title

Short description

Date/year

Optional image placeholder

Keep this section expandable so more activities can be added later.

5. Design Direction

The overall website should feel like a premium student magazine/publication website, not a generic college website.

Design style:

Editorial

Minimal

Sophisticated

Clean typography

Strong use of whitespace

Magazine-inspired layouts

Professional but youthful

Subtle animations and hover interactions

Avoid:

Excessive gradients

Glassmorphism

Neon colors

Overly rounded SaaS-style cards

Generic AI-generated landing page aesthetics

Use a refined editorial color palette such as off-white, black/charcoal, and muted accent colors.

6. Navigation

Create a simple navigation bar:

Paper & Pulse | About | Magazine | Activities | Office Bearers

Add a footer with:

Paper & Pulse

College/institution name placeholder

Social media placeholders

Copyright

7. Technical Structure

Build the website so that it is easy to maintain and expand later.

Important:

Keep magazine data separate so new PDF editions can easily be added.

Keep office bearer information separate so names, designations and photos can easily be updated.

Keep activities separate so new activities can be added without redesigning the page.

Use reusable components.

Make the entire website fully responsive for desktop, tablet and mobile.

For now, focus on creating the landing page, visual identity, navigation, office bearer placeholders, magazine section, and activities section. Do not build an admin panel or complicated backend yet.
Colour and font inspo given, dont make it too maroon, use complementary colours and make it classy
