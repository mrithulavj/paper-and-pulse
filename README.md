# Paper & Pulse

### The Magazine

Paper & Pulse is a modern digital platform for a college magazine and publication. It showcases magazine editions, publication activities, and the editorial team through a clean, editorial-inspired interface.

## Features

* Editorial-style responsive landing page
* About Paper & Pulse
* Magazine archive with PDF viewing
* Activities showcase
* Office Bearers profiles
* Reusable components
* Separate data structures for magazines, activities, and team members
* Designed for easy future expansion

## Design

The website follows a **minimal, sophisticated magazine aesthetic** with:

* Off-white, charcoal, black, and muted accent colours
* Strong typography
* Generous whitespace
* Subtle animations and interactions
* Magazine-inspired layouts

It intentionally avoids excessive gradients, glassmorphism, neon colours, and generic SaaS-style design.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS

## Development

```bash
git clone <repository-url>
cd <repository-name>
npm install
npm run dev
```

## Content

Magazine editions, activities, and office bearers are structured separately so new content can be added without redesigning the website.

Magazine PDFs can be uploaded later and opened directly through an embedded PDF viewer.

## Future Scope

* Complete magazine archive
* Magazine search/filtering
* Activity archive
* Social media integration
* Enhanced PDF reader
